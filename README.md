# RideMagic 🏍️

**Gear Up. Ride Beyond.**

RideMagic is a modern motorcycle riding gear website designed to showcase premium riding essentials through a bold visual style, immersive product displays, and interactive animations.

## ✨ Features

- Cinematic hero section with a featured helmet
- Interactive helmet selection
- Subtle mouse movement and visual effects
- Product showcases for motorcycle riding gear
- Responsive website layout
- Modern red and black visual theme

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🏁 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/stiyatheresa/ridemagic-3d.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your preferred local web server.
